# 开发者模式

在存档目录下建立 `developer.lua` 后，在里面填写

```lua
return {
	account = "你的用户名",
	password = "你的密码",
}
```

即可激活插件管理器的开发者模式。

此时，打开游戏，就可以发现，可以在本地插件视图中筛选自己开发的插件。这些插件卡片中出现了上传按钮，点击即可直接上传插件。上传规则如下：

1. 插件根目录中存在 `cover.*` 时，将会询问是否上传封面图片。
2. 插件根目录中的 `.git/`, `.backup/`, `cover.*`, `.tmp/` 会被排除出插件打包，避免插件体积膨胀。

直接通过插件管理器来上传插件，可以享受增量更新功能，从而避免重复上传巨大的美术资源。
